## 实际验证

- `/health` 返回 `databaseDriver: mysql`。
- 通过前端 `http://localhost:5173/api/v1/stats` 读取到 5,000 篇条目和 36,436 个章节。
- 前端代理列表接口返回总数 5,000、首页 50 篇。
- “矩阵”（`zh-6450`）详情包含 35 个章节，章节正文合计 13,701 字符。
- 列表搜索“矩阵”返回 918 个匹配，独立搜索接口的数据库回退也正常。
- Go 测试、Vue 类型检查和生产构建通过。

## 配套修正与限制

- 启动脚本读取 `.env` 的数据库类型，默认 MySQL，不再静默覆盖为 SQLite。
- 关闭 `.env` 中的 `DEMO_SEED`；界面显示当前连接的数据库类型。
- 章节标题字段改为长文本，避免维基引用标记导致标题超长而中断导入。
- 搜索 SQL 对 MySQL 保留字 `lead` 加引号，修复真实 MySQL 下的搜索错误。
- 修正 Windows PowerShell 5.1 对进程状态 JSON 数组的读取，重启已实际验证。
- 只验证本地 MySQL 与前端 API 对接；不代表 Elasticsearch 已索引或云端 AI/语音已启用。
- 源导出内容仍需校审：存在维基标记残留，部分数学表达式在原纯文本提取阶段已缺失；原始维基文本同时保存在数据库中，可供后续修复。

## 下次启动

在项目根目录运行 ` .\scripts\dev.ps1 `；修改后端后使用 ` .\scripts\dev.ps1 -Restart `。

不要直接重复运行导入器来更新已有社区内容：当前导入器会重建对应条目的章节，后续有用户批注时需先备份并设计章节锚点迁移。
