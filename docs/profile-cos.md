# 个人主页与腾讯云 COS 头像

登录后点击右上角头像或昵称，进入个人主页。可编辑昵称、个人简介、所在地和个人网站；账号、邮箱和角色不能在此修改。当前页面为个人资料设置，不是可分享的公开用户主页。评论、批注与回复公开显示昵称和头像，其他资料暂不对外展示。

## 配置：公有读、私有写

在项目根目录 `.env` 填写以下字段，**不要放入前端环境变量或提交密钥到 Git**：

```dotenv
COS_BUCKET=你的桶名称-APPID
COS_REGION=ap-guangzhou
COS_SECRET_ID=你的子账号SecretId
COS_SECRET_KEY=你的子账号SecretKey
COS_SESSION_TOKEN=
```

`COS_REGION` 替换为存储桶实际地域标识。`COS_BUCKET` 必须包含末尾的 APPID。
只有使用临时凭证时才填写 `COS_SESSION_TOKEN`，且必须与 SecretId/SecretKey 配套；本项目不自动刷新临时凭证。
建议给子账号仅授予目标桶 `mathwiki/avatars/*` 前缀的 `cos:PutObject` 权限，不要使用主账号全权限密钥。

桶沿用你已有的**公有读、私有写**设置。程序不创建桶、不更改桶或对象 ACL，上传对象继承桶权限。不要把写入权限开放给匿名用户。

填写后运行：

```powershell
.\scripts\dev.ps1 -Restart
```

Docker 部署：`docker compose up -d --build api web`。没有配置时个人资料编辑正常，头像上传按钮禁用并显示说明。页面的配置状态只检查字段是否齐全，不能证明云端凭证和权限有效。

## 上传与显示

- 登录用户只能上传或重置自己的头像；写接口保留会话和 CSRF 校验。
- JPG/PNG，原始文件不超过 5 MB，单边最多 4096，总像素最多 1200 万。前端居中裁剪预览，后端再次验证和重编码为 256×256 JPEG，移除原始文件元数据。
- 后端通过腾讯官方 Go SDK 签名上传到 `mathwiki/avatars/用户ID/随机版本.jpg`；每次更换生成新地址，避免旧缓存。单账户每 15 分钟最多 10 次上传尝试（单进程内存限流，集群需网关/共享限流）。
- 数据库只保存 URL、对象键和版本，不存图片二进制。浏览器直接 GET COS 的 HTTPS 公开地址，不经网站服务器转发、不需要临时读签名，也不需要浏览器跨域上传 CORS 配置。
- 当前上传经网站服务器中转到 COS，因此上传仍占服务器入站和少量出站流量；浏览头像不占网站服务器图片流量，但会产生 COS 请求与外网下行费用。建议在腾讯云控制台设置费用告警，流量较大时再评估 CDN。
- 本实现使用 COS 默认 HTTPS 域名，没有自动接入自定义 CDN 域名。
- 头像是公开图片，持有链接的人可以读取；不要上传不想公开的敏感照片。对象可缓存一天。

恢复默认头像仅解除数据库中的头像引用；更换头像也不会自动删除旧 COS 对象（避免误删，且不要求删除权限）。旧链接仍可访问，空间会累计。彻底清除旧照片需在控制台确认对象键后删除；不要对整个头像前缀配置按天删除的生命周期规则，否则在用头像也会被清除。

维基正文图片仍按原有 Wikimedia/镜像配置工作，本次没有批量下载或迁移文章插图到 COS。

实现参考：[腾讯云 Go SDK 上传对象文档](https://cloud.tencent.com/document/product/436/65644)。

## 验证状态

自动化测试使用模拟对象存储，覆盖图片格式/尺寸/大小限制、重编码、头像替换与重置、上传失败回滚、资料字段校验、越权与 CSRF 拦截、评论头像和公开 URL 无签名/密钥。它们不会向腾讯云上传文件。实际上传及匿名读取需要填写配置后另行联调。
