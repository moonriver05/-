# 标题优先搜索

页面搜索框调用 `/api/v1/articles`，保留分类、类型、个人收藏等筛选以及完整分页；在此接口上完成排序，不能只对当前页重排，也不能直接换成最多返回若干条结果的 `/search`。

有关键词时，默认显示「相关度」，按以下层级排序：

1. 标题完全匹配（英文忽略大小写）。
2. 原始维基标题完全匹配，或显示标题以关键词开头。
3. 显示标题或原始标题包含关键词。
4. 摘要、标签包含关键词。
5. 仅正文包含关键词。

同层级按更新时间降序、本地 ID 升序，确保翻页稳定。`%`、`_` 等按用户输入的普通字符搜索，不作为 SQL 通配符。原始标题不是完整的别名/同义词库；本次没有新增维基重定向采集或别名表。

搜索过程中可手动切换「最近更新 / 标题 / 难度」覆盖相关度。清空搜索恢复浏览时的排序选择，下一次开始搜索默认重新使用相关度。未输入关键词时「最近阅读」仍按个人阅读时间排序。

独立 `/api/v1/search` 的 Elasticsearch 查询也改为标题优先：精确标题、标题前缀、标题包含、标题分词匹配、摘要/标签、章节正文依次降序。使用 `constant_score` 和 `dis_max` 固定层级，防止正文词频抬高分数越过标题。英语匹配不区分大小写，通配符输入转义，关闭原来的自动模糊拼写匹配。现有索引映射不变；原始维基标题仅在 MySQL 路径检索，ES 仍使用当前已索引的显示标题。

Elasticsearch 不可用或无结果时，独立搜索回退到同一套 MySQL 标题优先排序。所有路径保留公开条目权限过滤，待审、驳回和已删除条目不公开。页面分页搜索当前仍使用 MySQL，不宣称已接入 ES 分页检索。

验证覆盖：旧日期精确标题置顶、60 篇正文匹配干扰、跨页顺序、原始标题、摘要/标签/正文层级、显式排序、筛选条件、SQL 特殊字符和未公开条目排除。ES 单元测试校验请求结构与响应排序；真实 ES 是否经过验证以本次运行记录为准。
