# 仅按标题搜索

页面搜索框调用 `/api/v1/articles`，使用 MySQL，保留分类、类型、个人收藏筛选及完整分页。只匹配显示标题，不匹配原始维基标题、摘要、标签或正文。

相关度依次为标题完全匹配、标题前缀、标题包含；同层级按更新时间降序、本地 ID 升序。SQL 的 `%`、`_` 等作为普通字符处理。用户可切换最近更新、标题、难度排序。

`ELASTICSEARCH_ENABLED=false` 使后端直接使用数据库标题搜索，避免等待 ES 连接失败。该开关不负责停止 Docker 容器。

可选 ES 索引只保存 pageId、title、language、updatedAt，title 为 keyword，单分片、零副本，不需要分词插件。旧全文索引映射不兼容，启用时须选择新索引名（例如 mathwiki_titles_v1）并运行 indexer。独立 `/api/v1/search` 使用精确、前缀、包含三个固定分数层级；页面分页接口仍使用 MySQL。

所有搜索结果保留公开条目权限过滤。测试覆盖标题排序、分页、筛选、特殊字符及排除正文匹配，ES 测试验证请求结构。
